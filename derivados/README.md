# derivados/

Texto extraído de los PDF (pdftotext u OCR), CSV limpios y figuras intermedias. **Se regeneran con scripts y nunca se editan a mano.** Si un derivado está mal, se corrige el script o se repite la extracción.

- Nombre: el mismo de la fuente en `raw/`, con la extensión nueva: `raw/datasheets/ds-03-bmp390.pdf` → `derivados/ds-03-bmp390.txt`.
- Los CSV limpios y las métricas de los análisis los escriben los scripts de `sim/`: `derivados/tst-004-limpio.csv`.
- El catálogo de derivados está en [index.md](../index.md), junto a su fuente.
