# Plantillas

Plantillas de nota para copiar. Usan el ID 000, que está reservado y nunca se asigna. Cada una trae un ejemplo marcado como ejemplo.

## Notas

- [requisito.md](requisito.md) — Requisito de la competencia (RQ) o de control (RC): texto, método, responsable y verificación.
- [decision.md](decision.md) — Decisión o trade study (DEC): opciones, criterios con pesos, puntuación y consecuencias.
- [prueba.md](prueba.md) — Prueba o vuelo (TST): plan, criterios ligados a RQ y RC, análisis con script y veredicto.
- [riesgo.md](riesgo.md) — Riesgo (RSK): enunciado, probabilidad × impacto, mitigación y contingencia.
- [interfaz.md](interfaz.md) — Interfaz entre subsistemas (ICD): señales, unidades, rangos y verificación.
- [acta.md](acta.md) — Acta de reunión (ACT): asistentes, decisiones y tareas.
- [entrega.md](entrega.md) — Entrega de revisión (REV): estructura oficial, cobertura de requisitos y comentarios de jueces.
