# Pruebas

Planes, análisis y veredictos de pruebas (TST-NNN). Un vuelo también es una prueba.

- `tst-NNN-nombre.md` (plantilla: [prueba](../Plantillas/prueba.md)). Datos crudos en `raw/pruebas/` o `raw/vuelos/`; análisis en `sim/`; figuras en `salida/figuras/`.
